# Puchica Mano — Digital Restaurant Menu

Puchica Mano is a restaurant web project that presents menu items in a digital format and helps customers explore the available options.

## Features

- Digital restaurant menu
- Interactive menu browsing
- Simple, user-friendly interface

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MauMar05/Puchica-Mano-que-rico.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Purpose

This project demonstrates the use of front-end web technologies to create a digital menu experience for a restaurant.
