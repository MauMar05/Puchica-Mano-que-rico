# Puchica Mano --- Restaurant Menu

A digital restaurant menu built to make it easier for customers to
explore food options and prepare an order.

## Overview

Puchica Mano is a web project for a restaurant. It presents menu items
in a digital format and provides an interactive way for customers to
choose items before contacting the restaurant to place an order.

## Features

-   Digital menu for browsing restaurant items
-   Menu categories and item search
-   Promotional items or offers
-   Shopping cart for selecting items
-   Automatic calculation of the order total
-   WhatsApp-based ordering flow
-   QR-code-friendly access to the digital menu
